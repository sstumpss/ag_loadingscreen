# IMPORTANT

### This is a fork / remake / improvement of nv_loading screen. Full credit goes to them.

- https://github.com/Seekiii/nv_loadingscreen


## Setup
 - Download and place in an appropriate folder, I have it in *[standalone]*.
 - Add the images / video / audio for your loadscreen: in html folder you need, audio.mp3, video.webm. In html/images folder you need your images as PNG.
 - Edit the config.js to reflect these assets, add the names of your images, what type of loadscreen.
 - Edit the rest of config.js, so add server name, description, etc.
 - Enjoy!
